DO NOT ASSUME (common wrong audits)
------------------------------------
- There is no custom fragment-shader gloss pipeline or SSR. Rig gloss is PNG layers + CSS filter / transforms.
- Physics is not a separate fixed-timestep engine; it lives in startLive2DLoop rAF with dt clamped (clampNum(rawDt, 0.004, 0.032) in assets/hq-companion.js).
- Impact audio uses cached decoded buffers + Web Audio createBufferSource per hit, with cooldowns (e.g. ~110 ms global, tit-pull motion accents ~1050 ms, dangle gap() in assets/hq-dangle-audio.js). Do not claim 60 new Audio() per second without tracing call sites.
- Reaction manifest loads manifest.runtime.json once at init (~250 KB path in assets/hq-companion-reaction-audio.js), not multi-MB JSON every frame.
